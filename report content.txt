# 🟧 **3.2 PROJECT DEVELOPED: NAMMA-HOMESTAY**

---

## **3.2.1 Introduction to Project**

The project titled **“Namma-HomeStay”** is an Android application designed to help rural home-stay owners manage their services and connect with travelers. In many rural areas, families have extra rooms and provide local food, but they are not able to use complex booking platforms due to lack of technical knowledge.

This application provides a simple and easy-to-use platform where hosts can add their home-stay details and manage their services. Travelers can browse these home-stays, view details such as facilities and menu, and contact the host directly.

The main goal of the project is to create a user-friendly system that works even for non-technical users and promotes rural tourism.

---

## **3.2.2 Literature Survey**

Before developing the application, existing platforms such as Airbnb and other booking systems were studied. These platforms provide advanced features but are often complex and not suitable for rural users who are not familiar with technology.

Most existing systems require email-based login, detailed forms, and multiple steps for listing properties, which can be difficult for non-technical users. They also focus more on urban accommodations and do not highlight local food and nearby experiences.

Based on this study, the idea of a simplified application was developed. The focus was on creating an easy interface with minimal steps so that rural users can manage their home-stay easily without technical difficulty.

---

## **3.2.3 Design / Methodology**

The project was developed using a step-by-step approach. First, the problem and requirements were clearly understood. Based on this, the features of the application were planned.

The user interface was designed with simplicity in mind. Screens were planned in such a way that users can easily navigate through the application. The design focused on clear layout, proper spacing, and easy-to-understand elements.

The development process included:

* Designing UI screens
* Implementing layouts in Android Studio
* Adding features step by step
* Connecting backend for data handling
* Testing each feature

This structured approach helped in developing the application in an organized way.

---

## **3.2.4 Implementation**

The application consists of two main user roles: **Traveller and Host**

### Traveller Features:

* Browse available home-stays
* Search based on location
* View home-stay details such as images, facilities, and menu
* Send inquiry to the host

### Host Features:

* Create and manage home-stay profile
* Add photos and description
* Set price and available rooms
* Add menu items
* Add nearby places (local guide)
* View and respond to traveler inquiries

The application was developed using Kotlin and Android Studio. The UI was designed to be simple and user-friendly. Backend services were used to store and manage data such as home-stays, menu items, and inquiries.

The overall application flow includes login, role selection, browsing, viewing details, and sending inquiries.

---

## **3.2.5 Testing / Results and Discussion**

The application was tested during different stages of development. Each feature was tested individually to ensure it works correctly.

UI testing was done to check alignment, spacing, and readability. Navigation testing was done to ensure smooth movement between screens. Data handling was tested to verify that correct information is displayed.

Some issues were found during testing, such as layout misalignment and navigation errors. These issues were fixed by making necessary changes and retesting.

After testing, the application was able to perform its core functions successfully. The main features such as browsing, viewing details, and inquiry system are working properly.

---

## **3.2.6 Conclusion of Project**

The Namma-HomeStay project was successfully developed with all basic features implemented. The application provides a simple solution for rural home-stay owners to manage their services and connect with travelers.

The project helped in understanding the complete development process, from planning and design to implementation and testing. It also improved skills in UI design, application development, and debugging.

Overall, the project demonstrates how a real-world problem can be solved using a simple and effective mobile application.
